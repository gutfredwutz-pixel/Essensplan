# Essensplan

Gemeinsamer Essensplan mit Einkaufsliste und Rezepten für Jakob und Frieda.

- Läuft als Web-App über GitHub Pages, auf dem iPhone über „Zum Home-Bildschirm“ wie eine App.
- Gemeinsame Daten liegen in Supabase (Einrichtung: `supabase-setup.sql` im SQL Editor ausführen).
- Spracherkennung (Whisper) und Texterkennung (Tesseract) laufen direkt auf dem Gerät.
